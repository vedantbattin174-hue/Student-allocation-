05 / DISCRETE MATHEMATICS

DML concepts used

The allocation interface is a concrete model of graph representation and matching.

CSE · DML PROJECT
01

Graph

A graph is a structure made of vertices and edges. Here, students and projects are vertices connected by compatibility edges.

02

Bipartite graph

A graph whose vertices split into two disjoint sets, with every edge joining one set to the other. No student connects directly to another student.

03

Vertex

A node in a graph. Each student and each project is represented by a vertex in its own partition.

04

Edge

An edge joins a student to a project when their skills or interests match, or when the pair is manually marked compatible.

05

Matching

A selected set of edges where no student is used more than once. Project slots also ensure each project's capacity is respected.

06

Maximum matching

A matching with the greatest possible number of allocated students for the current graph and project capacities.

07

Augmenting path

An alternating path that starts at an unmatched student and ends at an available slot. Flipping its edges increases matching size by one.

08

Adjacency matrix

A 0/1 table encoding which student-project edges exist. A 1 indicates compatibility, and a 0 indicates no edge.

09

Adjacency list

A compact representation that records the neighboring project vertices for each student.

10

Project capacity

The maximum number of students a project can accept. Internally, the algorithm models this as that many equivalent project slots.
